지지커플 QUIZ · 지현지원 청모 AWARDS 실시간 웹앱

주요 기능
- 지지커플 QUIZ 5문제: 동시 진행, 정답 공개, 점수 집계
- 지현지원 청모 AWARDS 5문항: 동시 투표 → 결과 공개 → 다음 어워즈
- 진행자 화면: 참가자 실시간 접속 현황, 현재 화면 확인, 응답 현황, QUIZ 점수, AWARDS 투표 현황
- 투표 → 결과 공개 → 다음 문제/어워즈 진행
- AWARDS 투표 상태 초기화 및 전체 게임 초기화
- 최종 결과: 지지커플 QUIZ / 지현지원 청모 AWARDS
- 관리자에서 문제 수정 기능은 제거되었으며, 문제와 정답은 이 최종본에 고정되어 있습니다.
- 새로 링크에 접속하면 첫 화면에서 시작합니다.

Render 설정
Build Command: pip install -r requirements.txt
Start Command: gunicorn server:app
